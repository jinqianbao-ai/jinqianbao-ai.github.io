# 金钱豹AI

一个面向中文AI爱好者的日报与交流社区。

**网站首页：** https://jinqianbao-ai.github.io/

**进入论坛：** https://github.com/jinqianbao-ai/jinqianbao-ai.github.io/discussions

## 在这里可以做什么

- 阅读每日AI行业动态和核验后的重点信息；
- 讨论模型、产品、开源项目、论文和行业变化；
- 分享AI工具、提示词、自动化工作流与真实实践；
- 提出使用问题，交流解决方法；
- 指出日报错误，补充来源或提交下一期线索；
- 参与论坛功能、内容方向和选题投票。

## 论坛版块

| 版块 | 内容 |
|---|---|
| AI日报 | 每日行业情报、来源核验和独立研判 |
| 分享交流 | AI工具、提示词、工作流、案例和踩坑记录 |
| 问答求助 | 使用问题、技术问题和经验交流 |
| 文内批注 | 在日报中选中一句话，原地评论、回复和点赞 |
| 投票调查 | 模型、工具与社区话题投票 |
| 综合讨论 | 其他值得讨论的AI话题 |

## 参与原则

- 区分事实、媒体报道、传闻和个人判断；
- 尽量附上原始来源；
- 欢迎纠错和不同观点，讨论具体问题，不攻击个人；
- 不公开账号密码、API密钥、私钥或未经授权的个人信息；
- 分享工具或项目时，请说明费用、限制和已知风险。

欢迎加入讨论，共同把有价值的AI信息整理得更清楚。
