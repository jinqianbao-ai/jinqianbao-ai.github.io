Claude Code系列｜第49期 · 进阶动手约30分钟｜按服务商计费

把代理安全测试接入提交前检查

适合让编码代理修改前后都留下可审查证据。环境：Claude Code官方CLI、可回滚代码仓库、Python 3.11+。命令依据官方CLI文档；版本参数变化时以官方参考为准。

printf '%s\n' '只分析 src/日期解析代码，不要编辑文件。输出：风险点、建议测试、需要人工确认的问题。' | claude -p

printf '%s\n' '只修复 src/日期解析代码中的已确认问题；不要读取或修改 .env、密钥、用户目录和仓库外文件。完成后运行现有测试，并输出修改文件列表、测试结果和剩余风险。' | claude -p --allowedTools 'Read,Edit,Bash'

git diff -- src/

成功标准：差异只在预期目录，测试有真实结果。常见坑是全盘命令执行、没有保存差异、只看口头总结。不该用：支付、生产部署、删除数据或不可逆迁移。

参考：Claude Code官方CLI文档。

Hermes Agent系列｜第49期 · 进阶动手约35分钟｜工具和模型按实际计费

用检查点记录“检索—核验—写入—验收”

适合把常驻任务拆成可恢复节点。示例只用于理解状态机，不代表具体部署配置。

from dataclasses import dataclass, field

@dataclass
class State:
    urls: list[str] = field(default_factory=list)
    verified: list[str] = field(default_factory=list)
    files: list[str] = field(default_factory=list)

def next_step(state: State) -> str:
    if not state.urls: return "检索"
    if len(state.verified) < 8: return "核验"
    if not state.files: return "写入"
    return "验收"

print(next_step(State()))

预期输出：检索。真实系统应保存输入、输出、时间和失败原因，并让写入幂等。不该用：没有明确状态边界或可验证结果时不要强套工作图。

参考：Hermes Agent官方文档。
下期预告：定时任务的幂等键、重试退避和人工升级路径。

Claude模型系列｜第49期 · 进阶动手约25分钟｜按API用量计费

用统一接口记录模型调用成本

环境：Python 3.11+、openai Python SDK、兼容接口地址和模型名。密钥只放环境变量。

import json, os, time
from openai import OpenAI

client = OpenAI(api_key=os.environ["AI_API_KEY"], base_url=os.environ["AI_BASE_URL"])
response = client.chat.completions.create(
    model=os.environ["AI_MODEL"],
    messages=[{"role":"user","content":"只回复：成本记录成功。"}],
    temperature=0,
)
print(json.dumps({"time":time.time(),"model":response.model,"text":response.choices[0].message.content,"usage":response.usage.model_dump() if response.usage else None}, ensure_ascii=False))

成功时看到确认语、模型名和usage字段。401通常是密钥或地址错误，404通常是模型名或路径不匹配，429表示限流；无usage时不要猜成本。不该用：服务商不兼容该接口时先用官方SDK。

参考：OpenAI Python SDK。
下期预告：故障切换、限流重试和上下文压缩，避免成本失控。

四、🤖 AI独立研判（非新闻事实）

【AI独立研判】基于本期已收集事实，未来1—4周的竞争主线会从单模型能力转向“模型—模拟环境—工具—算力融资”的闭环。Genie 4代表模拟世界，Claude药物案例代表专业流程，Meta和SpaceX代表资本化算力，LFM3和M6代表端侧扩散。

【AI独立研判】代理安全会从提示词防护升级为系统工程：权限、技能文件、记忆、通信拓扑、沙盒、日志和回归测试需要一起评估。Vera、Orbit和ClawSafety的共同方向是把安全结论从“模型说了什么”转移到“工具实际做了什么”。

【AI独立研判】值得观察：世界模型是否开放稳定接口；GPU租赁能否按期交付并产生收入；小型多模态模型是否形成端侧商业场景；版权诉讼是否推动训练数据许可价格和可追溯机制变化。

【AI独立研判】我可能判断错的地方：早期案例不等于规模化生产效果，融资承诺不等于算力上线，论文攻击成功率不能直接换算成现实风险，世界模型的视觉连续性也不等于物理世界理解。
