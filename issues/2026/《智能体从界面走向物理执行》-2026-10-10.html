Claude Code系列｜第40期：计划—实现—审查—测试最小闭环

难度：进阶　动手：40—60分钟　成本：免费起步，模型调用按账号或API计费　环境：Claude Code、Git、可回滚测试仓库。

先让代理只读并提出计划，再限制实现范围，最后由独立审查和测试决定是否交付。

你是计划代理。只读取当前仓库，不修改文件。请回答：目标、涉及文件、证据、最小修改方案、风险、验证命令。没有证据的判断标记为“未核验”。
你是实现代理。只按已确认计划修改文件。修改前列出将改变的文件；修改后运行项目已有测试或语法检查，输出实际命令、结果、差异摘要和未解决问题。不得自动提交。
你是独立审查代理。只检查当前差异和测试结果，不重写代码。检查是否超出计划、是否引入权限或数据风险、异常路径是否覆盖、测试是否真的验证目标。结论只能是“通过”“需返工”或“证据不足”。

常见坑：共用可写目录会让只读失效；只跑语法检查不能证明业务正确。生产数据、支付、交易或不可回滚操作不应只依赖提示词分工。

参考：Claude Code设置文档。什么情况下不该用：紧急止损或不可安全回滚时，先执行明确保护动作。

Hermes Agent系列｜第40期：让长任务按检查点恢复

难度：进阶　动手：30—45分钟　成本：免费起步，模型调用按服务计费　环境：Hermes Agent、可写知识库、阶段状态。

任务恢复规则：
1. 读取状态记录，只认最后一个“已验收”阶段。
2. 检查目标文件存在、非空、日期一致。
3. 已验收阶段不得重复写入；失败阶段从失败点重试。
4. 外部发布后读回目标页面，确认标题、日期和正文确实更新。
5. 任意验收失败，输出“未通过”和缺项，不得继续发布。

验证方法：人为中断在网页完成阶段，第二次运行应跳过已验收阶段，只重试验收或发布。不要把接口成功或文件存在当成最终成功。

参考：Hermes Agent文档。什么情况下不该用：没有稳定阶段边界、依赖不可重复随机状态时，不要伪造可恢复保证。

下期预告：第41期拆出独立审查节点，并加入证据路径回读和超时分类。

Claude模型系列｜第40期：用OpenAI兼容接口记录调用成本

难度：进阶　动手：30—40分钟　成本：按服务商实际调用计费　环境：Python 3.10+、兼容OpenAI SDK的服务商、环境变量密钥。

import json, os
from datetime import datetime, timezone
from openai import OpenAI
client = OpenAI(api_key=os.environ["AI_API_KEY"], base_url=os.environ["AI_BASE_URL"])
model = os.environ["AI_MODEL"]
price_in = float(os.environ.get("AI_PRICE_IN_PER_M", "0"))
price_out = float(os.environ.get("AI_PRICE_OUT_PER_M", "0"))
response = client.responses.create(model=model, input="请用三句话说明：为什么机器人智能体需要持续观察执行结果？")
usage = getattr(response, "usage", None)
input_tokens = int(getattr(usage, "input_tokens", 0) or 0)
output_tokens = int(getattr(usage, "output_tokens", 0) or 0)
cost = input_tokens/1_000_000*price_in + output_tokens/1_000_000*price_out
print(response.output_text)
print(json.dumps({"time":datetime.now(timezone.utc).isoformat(),"model":model,"input_tokens":input_tokens,"output_tokens":output_tokens,"estimated_cost":round(cost,8)}, ensure_ascii=False))
