Claude Code系列 · 进阶动手约30分钟｜按账户或API用量计费

用非交互管道做一次最小权限改动

环境：Claude Code、Git、Python 3.11+。适合小范围代码修复，不适合生产数据库、支付、真实交易或不可逆删除。

git status --short
printf '%s\n' '请只检查src/日期解析代码，先给出计划，不要编辑；得到人工批准后再修改。编辑后运行现有测试，并用中文报告文件、差异和测试结果。不要访问网络，不要读取.env、密钥或用户目录。' | claude -p
git diff -- src/

成功标准：计划、差异和测试结果齐全，差异只出现在预期目录。常见坑是任务边界过大、只看口头总结、不检查差异。参考：Claude Code官方CLI文档。

下期预告：把权限规则、hooks和测试组合成提交前闸门。

Hermes Agent系列 · 进阶动手约35分钟｜免费阅读，工具调用按实际计费

为常驻任务设置检查点和失败恢复

核心做法是把检索、核验、写入、验收拆成四个节点；每个节点只负责一种权限，并把状态写成可重复读取的记录。

from dataclasses import dataclass, field
@dataclass
class State:
    urls:list[str]=field(default_factory=list)
    verified:list[str]=field(default_factory=list)
    files:list[str]=field(default_factory=list)
def next_step(s:State):
    if not s.urls:return "检索"
    if len(s.verified)<8:return "核验"
    if not s.files:return "写入"
    return "验收"
print(next_step(State()))

预期输出为“检索”。每一步完成后保存状态，失败时从最近检查点恢复，不重复写入。参考：Hermes Agent官方文档、MCP官方文档。

下期预告：定时任务的幂等键、重试退避和人工升级路径。

Claude模型系列 · 进阶动手约25分钟｜按API用量计费

记录每次模型调用的输入、输出和失败成本

环境：Python 3.11+、服务商SDK或兼容OpenAI接口的客户端。密钥只放环境变量；不同服务商的价格必须以账单为准。

import os, json, time
from openai import OpenAI
client=OpenAI(api_key=os.environ["AI_API_KEY"],base_url=os.environ["AI_BASE_URL"])
r=client.chat.completions.create(model=os.environ["AI_MODEL"],messages=[{"role":"user","content":"只回复：成本记录成功。"}],temperature=0)
row={"time":time.time(),"model":r.model,"text":r.choices[0].message.content,"usage":r.usage.model_dump() if r.usage else None}
print(json.dumps(row,ensure_ascii=False))

成功时看到中文确认语、模型名和usage字段。401通常是密钥或地址错误，404通常是模型名错误，429表示限流；没有usage时不要猜成本，应查服务商账单。参考：OpenAI Python SDK。

下期预告：故障切换、限流重试和上下文压缩，避免账单失控。
