① Claude Code系列｜第19期：用子代理做独立审查

难度：进阶｜动手时间：30分钟｜成本：按账号和模型用量计费｜环境：Claude Code、Git项目、已有测试。先保存回滚点，再让主代理实现，独立角色只读审查差异和测试。

你是只读代码审查员。请先查看当前 Git 差异和已有测试，不修改任何文件。按功能正确性、边界条件、权限与隐私、测试覆盖列出问题；每个问题引用文件路径和行号，无法确认的标记为“未核验”。

常见坑是审查者继承主代理的错误假设，或把“未发现问题”当成“没有问题”。代码极少且无测试时不该使用多代理。下期预告：hooks与权限门禁。

③ Claude模型系列｜第19期：Agents API、SDK与直接API选型

难度：进阶｜动手时间：40分钟｜成本：按供应商用量计费｜环境：Python 3.11+、开发者账号和环境变量密钥。托管代理适合少写编排代码；SDK适合应用控制审批；直接API适合自建循环。

# agent_architecture_choice.py
import os
mode=os.getenv("AGENT_MODE","sdk")
choices={"managed":"托管代理","sdk":"应用内SDK","direct":"直接API"}
if mode not in choices: raise SystemExit("AGENT_MODE只能是 managed、sdk 或 direct")
print("运行方式：", choices[mode]); print("密钥状态：", "已配置（不显示内容）" if os.getenv("AI_API_KEY") else "未配置")

运行：export AGENT_MODE="sdk"; export AI_API_KEY="你的密钥"; python agent_architecture_choice.py。真实接入前确认模型ID、端点、价格和限流字段。不可逆写操作不该只凭此脚本自动执行。下期预告：上下文压缩与提示缓存。
