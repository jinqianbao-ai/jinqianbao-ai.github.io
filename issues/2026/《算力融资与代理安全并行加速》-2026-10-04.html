📚 AI实用教程

① Claude Code系列｜用非交互管道做“计划—实现—测试—审查”闭环

难度：进阶　动手时间：20分钟　成本：按账户方案计费　环境：Claude Code、Git项目、测试命令。

适合批量小修复。先只读，再计划，人工确认后实施，最后测试审查：

claude -p "先只读检查当前仓库：列出主要模块、测试命令和潜在风险。不要修改文件。用中文输出检查清单。"
claude -p "根据当前仓库的测试失败信息，提出最小修复方案。先不要改文件，列出将修改的文件和验证命令。"
claude -p "现在实施已确认的最小修复，修改后运行项目已有测试，并用中文总结变更、测试结果和未解决风险。"

成功标准是差异只涉及预期文件且测试真实运行。数据库迁移、支付、生产密钥和不可逆删除不适合无人值守串联。

依据：Claude Code官方文档。下期预告：权限分层、允许列表与高风险工具审批。

② Hermes Agent系列｜用技能、工具和定时任务拆分常驻代理

难度：进阶　动手时间：30分钟　成本：免费起步，模型调用计费　环境：Hermes Agent、只读信息源、投递目标。

把主控、检索、核验、写入、发布和验证拆成边界清楚的技能，主控统一权限和最终验收：

name: daily-research
schedule: "30 9 * * *"
steps:
  - skill: collect_sources
    permissions: [web_read]
  - skill: fact_check
    permissions: [web_read]
  - skill: write_report
    permissions: [file_write:report_dir]
  - skill: publish
    permissions: [publish:discussion]
  - skill: verify
    permissions: [web_read, file_read:report_dir]

成功标准是重复运行不生成重复索引或帖子。没有稳定输入、验收标准和可回滚产物时，不要急着做常驻自动化。

依据：Hermes Agent文档。下期预告：多子代理编排与故障恢复。

③ Claude模型系列｜用统一接口做成本记录与限流重试

难度：进阶　动手时间：25分钟　成本：模型调用费用，代码免费　环境：Python 3.11+、兼容接口、环境变量密钥。

import json, os, time, urllib.request
BASE_URL = os.environ["AI_BASE_URL"].rstrip("/")
API_KEY = os.environ["AI_API_KEY"]
MODEL = os.environ.get("AI_MODEL", "claude-sonnet-latest")
payload = json.dumps({"model": MODEL, "messages": [{"role":"user","content":"用三句话解释什么是代理系统。"}], "max_tokens": 300}).encode()
for attempt in range(4):
    req = urllib.request.Request(BASE_URL + "/v1/chat/completions", data=payload, headers={"Authorization":"Bearer " + API_KEY,"Content-Type":"application/json"}, method="POST")
    try:
        with urllib.request.urlopen(req, timeout=60) as r: data=json.loads(r.read().decode())
        print(json.dumps({"model":MODEL,"usage":data.get("usage",{}),"answer":data["choices"][0]["message"]["content"]}, ensure_ascii=False)); break
    except Exception as exc:
        if attempt == 3: raise RuntimeError("连续重试后仍失败，请检查地址、密钥、模型名和服务限流") from exc
        time.sleep(2 ** attempt)

密钥只放环境变量；没有用量字段不要自行估算账单。注意原生消息格式和兼容接口格式可能不同，具体模型名与价格以当前服务文档为准。

依据：Anthropic API文档。下期预告：上下文压缩、按任务选模型和故障切换。
