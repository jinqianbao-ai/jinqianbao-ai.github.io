重点一：英伟达联合六家金融机构，拟撬动逾 5000 亿美元第三方资本

信息分层：正式信息｜已确认

英伟达首席执行官黄仁勋 8 月 11 日宣布，与 Apollo、BlackRock、Blackstone、Brookfield、Goldman Sachs 和 KKR 建立独立融资平台，目标是在未来为 AI 基础设施动员超过 5000 亿美元第三方资本。英伟达强调，这不是单一基金、不是公司收入，也不是给单一客户的承诺；金融机构将独立审查客户、利用率、现金流和残值，英伟达在个别项目中可能提供最高占机会规模 25% 的残值支持。

① Claude Code 系列第 6 期：用 Git Worktree 隔离高风险重构

  • 难度： 进阶
  • 预计动手时间： 20—30 分钟
  • 成本： 功能免费；模型调用按账户方案计费
  • 环境版本： Claude Code 官方文档当前版本；Git 仓库
  • 适用场景： 上期已建立测试与只读安全审查，希望让重构不触碰主工作区。

在仓库根目录先把 Claude Code 工作树目录加入忽略文件，然后启动隔离会话： 

printf '\n.claude/worktrees/\n' >> .gitignore
git add .gitignore
git commit -m "忽略 Claude Code 工作树目录"
claude --worktree auth-refactor

Claude Code 会在 .claude/worktrees/auth-refactor/ 创建独立工作目录，并使用 worktree-auth-refactor 分支。进入后直接发送完整任务： 

请只在当前工作树中重构认证模块。先运行现有测试建立基线，再做最小改动；不得修改主工作区。完成后运行全部相关测试，调用只读安全审查子代理，最后列出提交、测试、未解决风险和建议合并方式。若测试失败，不要合并或删除工作树。

验证： 

git worktree list
git -C .claude/worktrees/auth-refactor status --short
git status --short

第一条应看到独立工作树；第二条显示隔离分支改动；主工作区不应出现同一批业务文件。退出交互会话时，Claude 会检查未提交改动和新提交，避免误删有价值工作。

常见坑： Worktree 只适用于 Git；新工作树不会自动带入被忽略的 .env，不要复制真实密钥进教程或仓库；首次交互使用可能需要先在仓库接受工作区信任。非交互 -p 会跳过该信任检查，自动化前应先确认目录和权限。

什么情况下不该用： 只有一个极小改动、没有并行任务，或项目不使用 Git 时，不必增加工作树复杂度。

参考：Claude Code 官方 Worktree 文档

https://code.claude.com/docs/en/worktrees

② Hermes Agent 系列第 6 期：用 Kanban 把长期任务变成可恢复工作流

  • 难度： 进阶
  • 预计动手时间： 20—35 分钟
  • 成本： 看板本身免费；工作代理按所选模型计费
  • 环境版本： 以 Hermes Agent 当前 Kanban 官方文档为准
  • 适用场景： 上期的多技能 Cron 已能定时运行，但需要把采集、核验、写作、复核拆成可追踪节点。

直接在 Hermes 对话中发送： 

请为“每日产品情报”建立一个持久 Kanban 工作流，共四个任务：
1. 采集：收集过去24小时官方发布与代码仓库更新；
2. 核验：逐条打开原始链接并标注可信度；
3. 写作：只使用已核验材料生成中文简报；
4. 复核：检查数字、日期、死链与事实/分析分区。

依赖关系必须是：采集完成后才能核验，核验完成后才能写作，写作完成后才能复核。
每个任务都要写明输入、预期产物、失败出口和完成标准；任何任务被阻塞时保留原因，不得静默跳过。复核通过后才标记整条工作流完成。

Hermes Kanban 是持久任务板：任务、交接、评论和附件写入同一 SQLite 看板，工作代理是独立进程，失败后可阻塞、解除阻塞并重跑。它与短期 delegate_task 不同：后者像函数调用，Kanban 更像可恢复队列。

验证方法： 在看板或 /kanban 入口检查四个任务是否都有状态、依赖和完成标准；故意让“核验”缺少一个来源，确认它进入阻塞而不是直接放行；补充链接后再解除阻塞。

常见坑： 不要让模型在工作代理内用 shell 调 hermes kanban，官方设计是代理使用 kanban_* 工具，人和自动化才使用 CLI／斜杠命令；任务粒度不要大到一次执行数小时，也不要细到每个链接一个任务；跨代理交接必须附产物或 URL。

什么情况下不该用： 父代理只需要一个几分钟内返回的简单答案时，使用普通子代理更轻；需要严格金融级恰好一次事务时，还应使用业务队列与幂等键。

参考：Hermes Agent Kanban 官方文档

https://hermes-agent.nousresearch.com/docs/user-guide/features/kanban

PRICES = {
    "claude-sonnet-5": {"input": 2.0, "cache_read": 0.2, "cache_write": 2.5, "output": 10.0},
    "claude-haiku-4-5": {"input": 1.0, "cache_read": 0.1, "cache_write": 1.25, "output": 5.0},
}

def part(tokens, price):
    return float(tokens or 0) * price / 1_000_000

daily = defaultdict(float)
with LEDGER.open(encoding="utf-8") as f:
    for line in f:
        x = json.loads(line)
        day = datetime.fromisoformat(x["time"]).date()
        if day.year != TODAY.year or day.month != TODAY.month:
            continue
        p = PRICES[x["model"]]
        daily[day] += (
            part(x.get("input_tokens"), p["input"])
            + part(x.get("cache_read_input_tokens"), p["cache_read"])
            + part(x.get("cache_creation_input_tokens"), p["cache_write"])
            + part(x.get("output_tokens"), p["output"])
        )

spent = sum(daily.values())
window = [TODAY - timedelta(days=i) for i in range(7)]
avg7 = sum(daily.get(d, 0) for d in window) / 7
remaining = max(BUDGET - spent, 0)
days_left = remaining / avg7 if avg7 else float("inf")
exhaust = TODAY + timedelta(days=int(days_left)) if avg7 else None

print(f"本月已用：${spent:.2f} / ${BUDGET:.2f}")
print(f"近7日平均：${avg7:.2f}/天")
print("预计耗尽：", exhaust.isoformat() if exhaust else "暂无足够用量")

if exhaust and exhaust.month == TODAY.month:
    print("建议：把检索、分类和格式整理降级到 Haiku；保留 Sonnet 处理最终推理与审查。")
elif spent > BUDGET * 0.8:
    print("建议：预算已超过80%，优先压缩上下文并提高缓存命中率。")
else:
    print("建议：当前预算轨迹可控，继续监测输出词元和上下文增长。")

常见坑： 七日均值会被一次性大任务放大；中转站可能改变字段或价格；预测是运行率估算，不等于发票。若账本跨时区，先统一到同一日期口径。

什么情况下不该用： 调用量极少、每月只有一两次大任务时，七日均值没有预测意义。

以下内容是基于本期已收集事实作出的分析，不是任何公司、监管机构或媒体的官方消息。
  1. 【AI独立研判】AI 基建的下一轮竞争会先发生在资产负债表，而不是模型榜单。 当 5000 亿美元级融资平台、2.4 亿美元专属推理合同和电力预测放在一起看，决定扩张速度的是谁能拿到低成本长期资本与真实电力。

  3. 【AI独立研判】智能体会从“无限记忆”转向“有注释的有限记忆”。 CLAUDE.md 增长研究、SkillZip、Copilot 持久记忆共同指向同一问题：记忆必须带来源、理由、适用范围和删除条件，否则只会堆高成本与冲突。
  4. 【AI独立研判】未来 1—4 周值得观察： 英伟达融资平台是否披露首批项目、利率与利用率门槛；Anthropic 文本水印的独立检测与抗编辑结果；Daybreak 在 Bedrock 的区域、审计与资格边界；Together AI 集群是否披露 GPU 数量和承诺用量。
  5. 【AI独立研判】我可能判断错的地方： 5000 亿美元是多年“可动员规模”，未必真正投入；技能压缩可能遗漏罕见但关键规则；文本水印也可能因误报或易移除而难以成为稳定治理工具。
