📚 AI实用教程

Claude Code系列｜第39期：只读调研代理与可写实现代理的交接

难度：进阶　动手：35—50分钟　成本：免费起步，模型调用按账号或API计费　环境：Claude Code、Git、两个独立工作目录。

让一个代理只读代码、查资料和提出修改建议，另一个代理才允许写入。先复制可回滚测试仓库；只读会话生成报告；人工检查来源和文件范围；将报告交给实现会话；实现代理先计划、再修改、最后运行测试。

你是只读调研代理。只允许读取当前仓库和明确给出的公开资料，不得修改、删除、提交文件，不得访问仓库外路径。请输出：问题定义、证据链接、涉及文件、可能方案、风险、建议测试。没有证据的内容标为“未核验”。
你是实现代理。只根据调研报告和当前仓库执行修改。先检查每条证据，再列计划；只修改计划中的文件；完成后运行测试并输出差异、命令、结果和未解决问题。不得自动提交。

常见坑：两个代理共用可写目录会破坏只读边界；报告没有来源位置时容易把猜测当事实。生产、支付或不可回滚数据不应只依赖提示词分工。参考：Claude Code设置文档。

Hermes Agent系列｜第39期：用幂等键和验收清单恢复长任务

难度：进阶　动手：30—45分钟　成本：免费起步，模型调用按服务计费　环境：Hermes Agent、可写知识库、可重复运行任务。

任务：恢复一份中断的日报生产。
1. 读取状态文件，只认最后一个“已验收”阶段。
2. 检查目标文件是否存在、非空且日期一致。
3. 每个外部写入使用唯一幂等键：日报日期 + 阶段名。
4. 已成功阶段不得重复写入；失败阶段从原阶段重试。
5. 验收：新闻8—12条、三条教程、HTML锚点无死链、分类页有当天链接、日志有当天记录。
6. 任意验收失败，输出“未通过”和缺项，不得继续发布。
7. 发布后读回论坛和静态页面确认更新。

第一次运行到中途停止，第二次应跳过已验收阶段，只重试失败阶段。不要把“文件存在”当成成功；发布接口返回成功也不等于内容已更新。涉及删除、交易或不可撤回消息时必须人工确认。参考：Hermes Agent文档。

下期预告：第40期把验收清单拆成独立审查节点，并加入证据路径回读。

Claude模型系列｜第39期：为OpenAI兼容接口加入请求级成本账本

难度：进阶　动手：30分钟　成本：按服务商实际调用计费　环境：Python 3.10+、OpenAI兼容服务商、环境变量中的密钥。

import json, os
from datetime import datetime, timezone
from openai import OpenAI
api_key=os.environ["AI_API_KEY"]
base_url=os.environ["AI_BASE_URL"]
model=os.environ["AI_MODEL"]
price_in=float(os.environ.get("AI_PRICE_IN_PER_M","0"))
price_out=float(os.environ.get("AI_PRICE_OUT_PER_M","0"))
client=OpenAI(api_key=api_key, base_url=base_url)
response=client.responses.create(model=model,input="请用三句话说明：为什么科研代理需要可复核证据链？")
usage=getattr(response,"usage",None)
input_tokens=int(getattr(usage,"input_tokens",0) or 0)
output_tokens=int(getattr(usage,"output_tokens",0) or 0)
cost=input_tokens/1_000_000*price_in+output_tokens/1_000_000*price_out
print(response.output_text)
print(json.dumps({"time":datetime.now(timezone.utc).isoformat(),"model":model,"input_tokens":input_tokens,"output_tokens":output_tokens,"estimated_cost":round(cost,8)},ensure_ascii=False))
python -m pip install "openai>=1.0,<2.0"
export AI_API_KEY="从服务商控制台复制的密钥"
export AI_BASE_URL="https://你的服务商地址/v1"
export AI_MODEL="服务商控制台显示的模型名"
export AI_PRICE_IN_PER_M="输入每百万token价格"
export AI_PRICE_OUT_PER_M="输出每百万token价格"
python cost_call.py

跑对的标志是得到中文回答并输出一行JSON。服务商不返回用量时，token数可能为0，必须以账单为准。限流要降低并发并退避；超时后先查请求记录再重试。不要把客户隐私、交易密钥或未脱敏内部资料发送给数据留存政策不清楚的中转服务。参考：Responses API。
