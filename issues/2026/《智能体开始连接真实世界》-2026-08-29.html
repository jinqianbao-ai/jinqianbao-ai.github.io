② Hermes Agent系列｜第17期：为定时任务设计可恢复的任务卡

难度：进阶｜动手：25分钟｜成本：免费，模型调用另计｜环境：Python 3.11+、Hermes Agent文档。

import json
from pathlib import Path
path = Path("task_card.json")
card = {"date":"2026-08-29","steps":[
 {"name":"检索","status":"done"},{"name":"核验","status":"pending"},
 {"name":"写作","status":"pending"},{"name":"发布","status":"blocked"}]}
path.write_text(json.dumps(card, ensure_ascii=False, indent=2), encoding="utf-8")
loaded=json.loads(path.read_text(encoding="utf-8"))
print("可重跑步骤："+"、".join(x["name"] for x in loaded["steps"] if x["status"]=="pending"))
print("发布步骤必须在人工确认后解除阻塞")

预期输出“可重跑步骤：核验、写作”。状态写入必须早于副作用，blocked不能当pending。参考：Hermes Agent文档。
下期预告：第18期接入多子代理汇总与人工批准状态。

③ Claude模型系列｜第17期：兼容中转站的故障切换账本

难度：进阶｜动手：30分钟｜成本：免费，实际调用按线路计费｜环境：Python 3.11+、requests、两条兼容OpenAI API的线路。

import os, requests
routes=[("主线路",os.environ["AI_BASE_URL_1"],os.environ["AI_API_KEY_1"]),
        ("备用线路",os.environ["AI_BASE_URL_2"],os.environ["AI_API_KEY_2"])]
payload={"model":os.environ["AI_MODEL"],"messages":[{"role":"user","content":"只回答：线路测试成功"}]}
for name,base,key in routes:
 try:
  r=requests.post(base.rstrip("/")+"/chat/completions",headers={"Authorization":"Bearer "+key},json=payload,timeout=20)
  r.raise_for_status(); print(name+"：HTTP "+str(r.status_code)+"，请求成功"); break
 except requests.RequestException: print(name+"：失败，切换下一线路")
else: raise SystemExit("所有线路失败，请检查地址、模型名、额度和限流")

设置AI_BASE_URL_1、AI_API_KEY_1、AI_BASE_URL_2、AI_API_KEY_2、AI_MODEL后运行；先确认中转站路径和模型名。不要无限重试或记录Authorization。高权限操作必须人工确认。参考：API参考。
下期预告：第18期加入指数退避、限流识别、请求ID对账和线路成本。
