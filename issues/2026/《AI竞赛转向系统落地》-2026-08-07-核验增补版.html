📚 AI实用教程（三条固定系列并行连载）

Claude Code 系列 · 第 4 期进阶20—30 分钟Hook 免费Python 3.10+

PostToolUse 自动跑最小测试集，并避免循环触发

适用场景：希望 Claude Code 每次修改 Python 或 TypeScript 文件后立即得到确定性测试反馈。官方 `PostToolUse` 在工具成功后触发；下面脚本读取文件路径，按扩展名选测试命令，并用锁文件防止循环。

创建 .claude/hooks/run_min_tests.py：

展开完整代码或命令
#!/usr/bin/env python3
import json, os, subprocess, sys
from pathlib import Path

payload = json.load(sys.stdin)
tool_input = payload.get("tool_input", {})
path_text = str(tool_input.get("file_path") or tool_input.get("path") or "")
path_text = path_text.replace("\\", "/").lower()
lock = Path(".claude/.test-hook.lock")

if lock.exists() or not path_text:
    raise SystemExit(0)
if path_text.endswith(".py"):
    command = [sys.executable, "-m", "pytest", "-q", "--maxfail=1"]
elif path_text.endswith((".ts", ".tsx")):
    command = ["npm", "test", "--", "--runInBand"]
else:
    raise SystemExit(0)

lock.parent.mkdir(parents=True, exist_ok=True)
lock.write_text(str(os.getpid()), encoding="utf-8")
try:
    result = subprocess.run(command, text=True, capture_output=True, timeout=180)
    output = (result.stdout + "\n" + result.stderr).strip()[-6000:]
    print(json.dumps({"hookSpecificOutput": {
        "hookEventName": "PostToolUse",
        "additionalContext": f"自动最小测试已执行。退出码：{result.returncode}\n{output}"
    }}, ensure_ascii=False))
finally:
    lock.unlink(missing_ok=True)

Hermes Agent 系列 · 第 4 期进阶15—25 分钟按模型调用计费官方 Cron

把定时任务做成可恢复、可审计、只报变化

Hermes Cron 在全新会话中运行，所以提示词必须自包含。官方模型选择顺序是“任务单独固定 → cron.model → 全局模型”；默认漂移保护会在全局模型变化后失败关闭，防止无人值守任务意外切到更贵模型。

展开完整代码或命令
hermes cron create "0 9 * * *" \
  "检查指定项目过去24小时的新提交、失败的持续集成任务和新发布版本。必须给出原始链接；如果没有任何变化，只输出 [SILENT]，不要解释。若网页或接口失败，输出中文失败原因，不得猜测。" \
  --name "项目晨检" \
  --workdir "C:/work/my-project" \
  --deliver telegram \
  --model "你已开通并核验的模型ID" \
  --provider "你已配置的服务商标识"

hermes cron run "项目晨检"
hermes cron runs "项目晨检" --limit 10
hermes cron status

暂停、改时间、恢复无需删除重建：

展开完整代码或命令
hermes cron pause "项目晨检"
hermes cron edit "项目晨检" --schedule "0 8 * * 1-5"

成功标准：历史记录出现 completed、failed 或 unknown；有变化时收到中文摘要，无变化时不投递。异常退出留下的 unknown 不会自动重跑，避免恢复后重复发送。

常见坑：Cron 表达式按运行环境时区解释；任务提示词漏写 URL、仓库名与格式会缺上下文；任务名可重复，重名时修改会被拒绝。外部写入仍需业务幂等键。
什么情况下不该用：需要毫秒级触发、强事务保证或法律意义必达通知时，不应只依赖普通 Cron。

Claude 模型系列 · 第 4 期进阶20—30 分钟正式请求按量计费Python 3.10+ / httpx 0.27+

先数词元，再压缩上下文并记录用量账本

官方说明：系统提示、历史消息、工具、图片、文档和输出都占上下文；提示缓存只改变费用，不减少上下文。下面程序先调用词元计数接口，超过预算时用确定性规则保留关键决定和最近消息，再正式请求并写入 JSONL 账本。

展开完整代码或命令
import json, os
from datetime import datetime, timezone
from pathlib import Path
import httpx

BASE_URL = os.getenv("ANTHROPIC_BASE_URL", "https://api.anthropic.com").rstrip("/")
API_KEY = os.environ["ANTHROPIC_API_KEY"]
MODEL = os.environ["ANTHROPIC_MODEL"]
BUDGET = int(os.getenv("TOKEN_BUDGET", "120000"))
LEDGER = Path("claude_usage.jsonl")
HEADERS = {"x-api-key": API_KEY, "anthropic-version": "2023-06-01",
           "content-type": "application/json"}
messages = [
 {"role":"user","content":"项目目标：把客服知识库改造成可审计问答系统。"},
 {"role":"assistant","content":"已确认：所有答案必须带来源，低置信度转人工。"},
 {"role":"user","content":"关键决定：禁止模型直接退款，只能创建待审批工单。"},
 {"role":"assistant","content":"收到，后续保留该权限边界。"},
 {"role":"user","content":"请给出今天可执行的三步上线清单。"}
]

def count(client, rows):
    r = client.post(f"{BASE_URL}/v1/messages/count_tokens", headers=HEADERS,
                    json={"model": MODEL, "messages": rows})
    r.raise_for_status()
    return r.json()["input_tokens"]

def compact(rows):
    keys = ("目标", "决定", "禁止", "必须")
    keep = [m for m in rows if any(k in str(m["content"]) for k in keys)] + rows[-4:]
    unique = []
    for item in keep:
        if item not in unique: unique.append(item)
    return unique

with httpx.Client(timeout=60) as client:
    before = count(client, messages)
    used = compact(messages) if before > BUDGET else messages
    after = count(client, used)
    r = client.post(f"{BASE_URL}/v1/messages", headers=HEADERS,
        json={"model": MODEL, "max_tokens": 800, "messages": used})
    r.raise_for_status()
    data, usage = r.json(), r.json().get("usage", {})
    record = {"time": datetime.now(timezone.utc).isoformat(), "model": MODEL,
      "count_before": before, "count_after": after,
      "input_tokens": usage.get("input_tokens", 0),
      "cache_read_input_tokens": usage.get("cache_read_input_tokens", 0),
      "cache_creation_input_tokens": usage.get("cache_creation_input_tokens", 0),
      "output_tokens": usage.get("output_tokens", 0)}
    LEDGER.open("a", encoding="utf-8").write(json.dumps(record, ensure_ascii=False)+"\n")
    print(f"压缩前：{before}，压缩后：{after}")
    print("".join(x.get("text", "") for x in data.get("content", [])))
