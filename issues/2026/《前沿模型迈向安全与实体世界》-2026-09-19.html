Claude Code系列｜把权限、钩子和测试串成一条安全流水线

本期把重点从“让代理写代码”推进到“让代理写完必须经过检查”。钩子（hooks）是在工具调用前后自动运行的脚本；权限规则负责限制哪些动作需要人工确认。

在项目根目录创建 `.claude/settings.json`：
{
  "permissions": {
    "deny": ["Bash(rm -rf *)", "Bash(git push *)"],
    "ask": ["Bash(git commit *)", "Bash(npm install *)"]
  },
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{"type": "command", "command": "python -m compileall ."}]
    }]
  }
}

claude -p "请先阅读项目测试说明，只修改一个最小文件；完成后运行已有测试并报告失败原因。"

1. 先复制项目并确认已有测试命令，不要让代理直接接触生产凭证。 2. 把删除、推送和安装依赖列为拒绝或人工确认动作。 3. 为编辑后的文件配置自动语法检查；看到命令返回 0 才算通过。 4. 用非交互模式执行一次小改动，检查代理是否在测试失败时停下来。 5. 最后人工查看差异，再决定是否提交。 常见坑：钩子命令依赖本机解释器；如果项目不是 Python，就把检查命令换成项目已有的 lint/test。权限规则写得过宽会让代理无法工作，写得过松则失去边界。什么情况下不该用这个方法：需要直接改生产环境、涉及真实密钥或不可逆数据时，不应只靠 Claude Code 钩子保护。

Hermes Agent系列｜用技能、工具和定时任务构成可审计工作流

本期把常驻调度拆成三层：技能负责稳定方法，工具负责外部动作，定时任务负责触发。核心不是让代理无限自主，而是让每一步都有输入、权限和验收。

# 面向读者的示例配置（请按当前 Hermes 文档字段核对）
job:
  name: "每日资料整理"
  schedule: "30 9 * * *"
  skill: "research-and-verify"
  tools: ["web_search", "read_file", "write_file"]
  guardrails:
    require_source_url: true
    require_local_validation: true
    no_external_publish_without_review: true

# 运行前先做低风险演练：只输出草稿，不发布、不修改外部系统

1. 先建立一个只读技能：输入是关键词，输出是带来源的事实表。 2. 给工具逐项授权，不要把写入、发布和支付类工具默认放入列表。 3. 定时任务先指向测试目录，验证日期、失败重试和重复运行的幂等性。 4. 设置“无来源不得进入正文”“校验失败不得发布”两个硬门槛。 5. 运行三次相同输入，检查是否重复写入和是否留下审计记录。 常见坑：技能文件与任务规则重复，导致维护冲突；定时任务没有超时和失败记录；把“能调用工具”误当成“允许完成副作用”。什么情况下不该用这个方法：任务会自动下单、发消息或修改重要数据时，必须再加人工批准或独立风控层。

Claude模型系列｜用原生消息接口记录用量与成本

不要先做复杂中转。先用原生消息接口把请求、响应、输入令牌和输出令牌记录下来，成本对账才有基础。示例故意把模型名和价格放在环境变量中，避免把旧价格写死。

import json, os, urllib.request

api_key = os.environ["ANTHROPIC_API_KEY"]
model = os.environ["ANTHROPIC_MODEL"]
body = json.dumps({
    "model": model,
    "max_tokens": 300,
    "messages": [{"role": "user", "content": "用三句话解释什么是检索增强生成。"}]
}).encode("utf-8")
req = urllib.request.Request(
    "https://api.anthropic.com/v1/messages", data=body, method="POST",
    headers={"x-api-key": api_key, "anthropic-version": "2023-06-01", "content-type": "application/json"}
)
with urllib.request.urlopen(req, timeout=60) as resp:
    data = json.load(resp)
print("文本：", "".join(x.get("text", "") for x in data.get("content", [])))
print("用量：", json.dumps(data.get("usage", {}), ensure_ascii=False))

1. 在环境变量中设置 `ANTHROPIC_API_KEY` 和你已确认可用的 `ANTHROPIC_MODEL`，不要把密钥写进代码。 2. 运行脚本，看到“文本”和“用量”两行即表示请求完成。 3. 把日期、模型、请求类型、输入令牌、输出令牌写入本地账本。 4. 价格表单独维护，并标注生效日期；不要用搜索摘要猜价格。 5. 遇到 429 限流，采用指数退避；遇到 401，检查密钥来源和环境变量；遇到模型不存在，重新查官方模型列表。 什么情况下不该用这个方法：需要跨供应商自动切换、严格数据驻留或大规模并发时，应先设计网关、脱敏和预算闸门，再接入生产。
