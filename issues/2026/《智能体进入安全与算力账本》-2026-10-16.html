Claude Code系列｜第44期｜进阶

用Hooks把测试变成提交前门禁

动手时间：30—45分钟｜成本：免费；模型调用按账户方案计费｜环境：Claude Code与可运行测试的代码仓库

接上期隔离代码审查：把自动检查放在提交前，但不让钩子替你绕过人工审阅。建议先在测试仓库试运行。

mkdir -p .claude/hooks
cat > .claude/hooks/pre-commit-check.sh <<'SH'
#!/usr/bin/env bash
set -euo pipefail
if [ -f package.json ]; then
  npm test
elif [ -f pyproject.toml ]; then
  python -m pytest
else
  echo "未识别测试入口，请先定义测试命令" >&2
  exit 1
fi
SH
chmod +x .claude/hooks/pre-commit-check.sh

验证：手动运行脚本，测试成功才允许继续；测试失败时修复，不要把钩子改成成功返回。参考：Claude Code Hooks文档。下期预告：第45期把Hooks输出接入独立安全审查，并为高风险文件设置人工确认。

Hermes Agent系列｜第44期｜进阶

把并行调研结果变成结构化验收表

动手时间：20—30分钟｜成本：按实际模型调用计费｜环境：支持委派子代理的Hermes Agent

不要让多个子代理返回散文。给每个代理同一份字段契约，主代理只接受字段完整、来源可回查的结果：

请研究“某项AI产品发布”并严格返回：
1. 结论：已确认／待确认／不采纳
2. 官方来源：最多3个URL
3. 可核验事实：最多5条，每条包含日期或数字依据
4. 未确认部分：逐条说明证据缺口
5. 对读者的影响：不超过3句
6. 下一步核验：最多2项
不要复制英文原文，不要把推测写成事实。

验证：主代理逐项检查字段、URL和来源层级；互不依赖时并行，依赖前项时串行。参考：Hermes委派文档。下期预告：第45期建立“主代理—事实核验—反方审查”三段式交接格式。

Claude模型系列｜第44期｜进阶

记录每次请求的Token与失败类型

动手时间：30—40分钟｜成本：按API实际用量计费｜环境：Python 3.10+、Anthropic官方SDK、环境变量ANTHROPIC_API_KEY

成本优化首先要有账。下面示例不写真实密钥，并把成功、限流、网络失败分开记录：

import os
import anthropic

client = anthropic.Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])
try:
    r = client.messages.create(
        model="claude-opus-5-5",
        max_tokens=300,
        messages=[{"role": "user", "content": "用三句话说明为什么要记录模型调用成本。"}],
    )
    print("成功", r.usage.input_tokens, r.usage.output_tokens)
    print(r.content[0].text)
except anthropic.RateLimitError:
    print("限流：记录请求时间，按官方建议等待后重试")
except anthropic.APIConnectionError:
    print("网络连接失败：不要把本次请求计为成功")

验证：成功输出应包含输入和输出Token字段；异常时只记录错误类别，不记录密钥。参考：Anthropic Messages API。下期预告：第45期做一张“模型—任务—Token—失败—重试—实际成本”对账表。
