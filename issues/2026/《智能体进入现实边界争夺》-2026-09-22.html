OpenAI 开放 Agents API 公测，把长会话、工具使用、文件和代码执行、子智能体编排以及上下文管理组合成统一接口。托管沙箱按标准容器费用计费，模型调用和工具使用另行计费。竞争焦点从模型接口扩展到运行时、沙箱和恢复机制。

GitHub Copilot 推出 HydraFusion，多模型编排以降低编码成本

GitHub 介绍研究预览 HydraFusion：系统先规划，再在不同模型之间选择直接完成、起草后审查修订或升级到更强模型的工作流。官方称特定离线评测中某基准质量提高 4.9 个百分点、估算成本降低 67%，但结果依赖实验配置。

为什么重要：工具开始从选择最强模型转向动态选择工作流，成本核算必须包含审查、重试、升级和回退。

Claude Code 系列第24期｜进阶｜20—30分钟｜按量计费

用非交互管道做“实现—审查—测试”闭环

适合把小功能交给终端代理，同时不允许它在没有测试和审查结果时宣称完成。环境：Claude Code、Git、Python 3.11+。参考：官方 CLI 文档。

claude -p "请阅读当前仓库，列出实现用户注册邮箱校验所需的文件、风险和测试计划。不要修改任何文件。输出中文。"
claude -p "根据分析实现邮箱校验。只修改必要文件；先写或补充测试，再运行测试。输出修改文件、测试命令、测试结果和风险。"
claude -p "只审查 git diff 和新增测试。检查输入校验、异常处理、权限边界和回归风险。不要修改文件。"

常见坑是把无报错当成测试通过，或让同一个代理给自己盖章。支付、生产数据库、真实交易和不可逆迁移不应只靠此方法。

Hermes Agent 系列第24期｜进阶｜30—45分钟｜按实际用量

用 cron + 只读工具做可恢复的每日情报流程

把任务拆成采集、核验、写入、验收四步；采集只读网页，写入只允许目标目录，发布前重新读取文件并检查链接。

name: ai-daily-research
schedule: "30 9 * * *"
timezone: Asia/Shanghai
steps:
  - name: collect
    tools: [web_search, web_extract]
    write: false
  - name: verify
    write: false
  - name: compose
    write_roots: ["G:/小唐的维基百科/维基/来源/AI日报/"]
  - name: audit
    require: ["新闻条目 >= 8", "三个教程均包含下期预告"]

每一步都要有明确产物，发布失败要保留本地文件并记录失败环节。参考：Hermes Agent 文档。

下期预告：第25期讲多子代理编排：检索、核验与主代理统一验收。

Claude 模型系列第24期｜入门｜15—20分钟｜按量计费

用环境变量和最小日志做 API 成本对账

不要把密钥写进代码、聊天记录或 Git。记录请求时间、模型、输入输出 token、请求 ID 和失败类型，再按价格页对账。

from decimal import Decimal
import os
model=os.environ.get("MODEL_NAME","示例模型")
in_tok=Decimal(os.environ.get("INPUT_TOKENS","1000"))
out_tok=Decimal(os.environ.get("OUTPUT_TOKENS","500"))
in_price=Decimal(os.environ.get("INPUT_USD_PER_MILLION","1"))
out_price=Decimal(os.environ.get("OUTPUT_USD_PER_MILLION","2"))
total=in_tok/Decimal(1000000)*in_price+out_tok/Decimal(1000000)*out_price
print(f"模型：{model}\n合计：${total:.8f}")

运行：MODEL_NAME="step-5-preview" INPUT_TOKENS=200000 OUTPUT_TOKENS=20000 INPUT_USD_PER_MILLION=1 OUTPUT_USD_PER_MILLION=2.7 python cost_check.py。注意缓存、推理 token、工具调用和重试费用。

下期预告：第25期比较中转站 base_url、官方端点和故障切换，重点防止重复扣费。

AI独立研判（非新闻事实）

【AI独立研判】准入权会成为智能体产品的第一竞争壁垒

这是基于本期事实作出的分析，不是官方消息。运行时之外还有网站、账户、支付和责任系统；成功的智能体需要可验证身份、最小权限、可追溯操作和纠错机制。

【AI独立研判】开放权重的分水岭是许可与可复现

Step 5 Preview 的 API 先行和 Qwen-Image-2.1 的完整模型卡形成对照。市场会把开放拆成能否下载、能否商用、能否第三方复现三个问题。

【AI独立研判】安全评估将从模型分数转向工作流证据

轨迹评测与多模型成本核算都说明，采购方会关注完整任务成功率、重试率、越权率、人工接管率和单位任务成本。

【AI独立研判】我可能判断错的地方

如果 Amazon 与 Meta 很快通过标准化授权解决 Muse 接入，平台准入权的重要性可能被高估；如果 StepFun 发布权重时许可宽松，开放权重扩散也可能更快。
