今日主线：本地智能与代理安全并进

微软在 Windows 上推进混合智能：简单或隐私敏感任务在本机完成，复杂任务再交给云端；同时用微软执行容器限制代理的文件、网络和身份边界。Anthropic 同日扩大网络安全核验计划，说明高能力模型的商业化正在从“开放能力”转向“分级授权”。

代理竞争的核心从单纯模型能力，转向本地算力、执行沙箱、身份审计和可撤销权限的组合。生物数据基础设施、AI 芯片融资和开放开发工具继续扩张，安全控制不再是发布后的附加条款，而是产品架构的一部分。

Claude Code 系列｜第38期：用最小权限和提交前检查保护编码代理

难度：进阶　动手：30—45分钟　成本：免费起步，模型调用可能收费　环境：Claude Code、Git、可回滚测试仓库。

新建示例仓库；在项目规则中限制仓库外访问、密钥和生产配置；按官方 hooks 文档配置提交前检查；让代理先计划、再改代码、最后运行测试；逐项检查修改范围、测试真实性和失败说明。

你现在只处理当前 Git 仓库。先读取项目规则和已有测试，不要访问仓库外文件，不要读取任何密钥或生产配置。先给出修改计划，得到计划后再改代码。完成后运行相关测试，报告命令、结果和未解决问题；测试失败时禁止声称完成。

常见坑：hooks 事件和路径可能随版本变化，先看官方文档。生产、支付或不可回滚数据不应只依赖 hooks，应使用隔离环境和人工审批。参考：Claude Code hooks。

Hermes Agent 系列｜第38期：把常驻任务拆成“调度、执行、验收”三段

难度：进阶　动手：40分钟　成本：免费起步，模型调用按服务计费　环境：Hermes Agent、可写工作目录、只读资料目录。

把常驻代理拆成调度阶段、执行阶段和验收阶段；调度只决定任务，执行只使用明确工具，验收检查文件、链接、数量和失败边界。

# AI日报验收技能
目标：验收一份中文AI日报，不负责系统维护，不负责创建定时任务。
必须检查：北京日期和期号；新闻为8至12条；三条教程线齐全；事实与研判分区；HTML目录无死链和横向溢出；Markdown、HTML、分类页和日志真实存在。
失败处理：任何一项失败都输出“未通过”和具体缺项，不得声称完成。

常见坑：调度提示词不能替代工具权限；只读必须在工具层落实；失败重试要幂等。涉及交易、删除数据或不可撤回消息时必须人工确认。参考：Hermes Agent 文档。

Claude 模型系列｜第38期：用 OpenAI 兼容接口接入中转站并做成本记录

难度：入门　动手：20分钟　成本：取决于服务商，先用小额度测试　环境：Python 3.10+、中转站地址和密钥。

import os
from openai import OpenAI

api_key = os.environ["AI_API_KEY"]
base_url = os.environ["AI_BASE_URL"]
model = os.environ["AI_MODEL"]
client = OpenAI(api_key=api_key, base_url=base_url)
response = client.responses.create(
    model=model,
    input="请用三句话解释：为什么智能体需要执行沙箱？",
)
print(response.output_text)
print("请求已完成，request_id=", getattr(response, "_request_id", "未提供"))
python -m pip install "openai>=1.0,<2.0"
# macOS/Linux
export AI_API_KEY="从服务商控制台复制的密钥"
export AI_BASE_URL="https://你的服务商地址/v1"
export AI_MODEL="服务商控制台显示的模型名"
python call_model.py

跑对的标志是得到中文回答且没有打印密钥。若服务商不支持 Responses API，应按其官方兼容说明改用明确支持的接口。限流要指数退避，超时后先查用量再重试。

🤖 AI独立研判（非新闻事实）

【AI独立研判】基于已收集事实，未来1—4周最值得观察的不是本地模型是否全面替代云端，而是本地模型是否被纳入企业身份、审计和策略管理。

【AI独立研判】高风险能力可能被拆成不同访问层：普通用户获得保守版本，核验后的安全团队获得更高权限；审核、撤权和事故披露会成为新信任基础。

【AI独立研判】AI基础设施融资的风险正从芯片够不够转向长期合同能否覆盖折旧和利息。若模型价格下降快于资产回收速度，债务化扩张会放大波动。

【AI独立研判】工具调用安全将成为多模态代理的独立评测轴，产品应公布浏览、视觉操作和外部 API 接入后的拒答、误执行与恢复数据。

【AI独立研判】我可能判断错的地方：本地代理仍在逐步推出，硬件宣传性能可能与实际工作负载有差距；SIGMA等论文尚未充分独立复现；媒体融资金额可能在交割前改变。
