Hermes Agent系列｜第41期：把外部写入拆成可回读的证据链

难度：进阶　动手时间：35—50分钟　成本：免费起步；模型调用按服务计费

环境与账号：Hermes Agent、可写知识库、一个需要生成文件并发布的长任务。

适用场景：为每个阶段保存“目标、输入、写入对象、回读结果、失败原因”五项证据。外部接口返回成功后，必须重新读取标题、日期和正文，而不是只看返回码。

请把本任务分为调研、撰写、本地验收、外部发布四个阶段。每阶段结束时列出实际证据；发布阶段必须读回目标页面，确认标题、日期、正文和链接。若回读失败，保留本地成品并明确报告外部发布未完成。
任务阶段记录格式：
1. 阶段名：本地文件完成
2. 目标：文件存在且非空
3. 写入：记录绝对路径和日期
4. 回读：再次读取并检查标题、日期、必需栏目
5. 结论：通过／未通过；未通过不得进入下一阶段

Claude模型系列｜第41期：为OpenAI兼容接口加入限流重试与成本上限

难度：进阶　动手时间：40—60分钟　成本：按服务商实际调用计费；建议先用低额度测试

环境与账号：Python 3.10+、兼容OpenAI SDK的服务商、环境变量中的密钥；接口是否支持Responses API需先查服务商文档。

适用场景：把失败分成超时、限流、认证失败和服务端错误；只有限流与暂时性服务端错误可以退避重试，认证失败和参数错误应立即停止。

export AI_API_KEY="从服务商控制台复制的密钥"
export AI_BASE_URL="https://你的服务商地址/v1"
export AI_MODEL="服务商控制台显示的模型名"
python -m pip install "openai>=1.0,<2.0"
python retry_call.py
import os
import time
from openai import OpenAI

client = OpenAI(api_key=os.environ["AI_API_KEY"], base_url=os.environ["AI_BASE_URL"], timeout=30)
model = os.environ["AI_MODEL"]

for attempt in range(3):
    try:
        r = client.responses.create(model=model, input="用两句话解释什么是限流。")
        print(r.output_text)
        break
    except Exception as e:
        text = str(e).lower()
        temporary = any(x in text for x in ["429", "rate limit", "timeout", "503", "502"])
        if not temporary or attempt == 2:
            raise
        time.sleep(2 ** attempt)
