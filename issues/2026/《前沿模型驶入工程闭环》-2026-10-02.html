今日主线：模型开始成为工程系统里的原生操作者

Google 的 Gemini 4 Argon 把长程推理、代码迁移与网络防御放在同一模型中，并先交给可信网络防御者测试；OpenAI 与 Synopsys 则要让专用模型直接操作电子设计自动化工具，反复优化芯片。AWS 的轻量决策模型、RoboSkill 的技能复用循环和 CodeActionBench 的具身代码评测，则把大模型系统拆成选择、执行、反馈和验证。

  • 能力发布与安全发布分离：高风险能力先进入受控人群。
  • 专用模型价值来自工具闭环：不是只会讲知识，而是能操作真实工具并获得反馈。
  • 执行成本推动模型分层：大模型处理难题，小模型负责路由，确定性程序负责约束。

用 Hook 与权限规则阻止访问敏感目录

适用场景：允许代理修改代码，但禁止读取 .env、密钥目录和生产配置。官方文档说明 PreToolUse Hook 在工具执行前触发，退出码2可阻止工具调用。

import json, sys
from pathlib import Path
payload = json.load(sys.stdin)
tool_input = payload.get("tool_input", {})
raw_path = tool_input.get("file_path") or tool_input.get("path") or ""
path = Path(raw_path).as_posix().lower()
blocked = ("/.env", ".env", "/secrets/", "/.ssh/", "/production/", "id_rsa", "credentials.json")
if any(x in path for x in blocked):
    print(f"已阻止访问敏感路径：{raw_path}", file=sys.stderr)
    sys.exit(2)
sys.exit(0)

验证：普通源文件应正常读取；.env 或 secrets/demo.txt 应显示中文阻止原因且工具不执行。常见坑：只写提示词、不设门禁；Hook 异常仍返回0；只拦截 Read 忘记 Edit/Write。

什么情况下不该用：必须处理生产密钥或不可逆线上操作时，不要仅靠 Hook 授权代理。

Hermes Agent 系列第32期进阶35—50分钟标准库免费

建立“退回补证—复核—入库”状态机

适用场景：多代理并行收集新闻时，主代理不能把“有标题”当成“证据合格”。

from dataclasses import dataclass, field
from enum import Enum
from urllib.parse import urlparse
class State(str, Enum):
    COLLECTED="已收集"; RETURNED="退回补证"; REVIEW="等待复核"; ACCEPTED="已入库"
@dataclass
class EvidenceCard:
    title:str; url:str; summary:str; confidence:str
    unchecked:list[str]=field(default_factory=list); state:State=State.COLLECTED
    def valid_url(self):
        p=urlparse(self.url); return p.scheme in {"http","https"} and bool(p.netloc)
    def first_review(self):
        bad=[]
        if not self.title.strip(): bad.append("缺中文标题")
        if not self.valid_url(): bad.append("缺有效原始链接")
        if len(self.summary.strip())<30: bad.append("摘要证据不足")
        if self.confidence not in {"高","中","低"}: bad.append("可信度未分层")
        self.state=State.RETURNED if bad else State.REVIEW
        return bad
card=EvidenceCard("某公司发布新模型","https://example.com/official","官方页面说明用途、范围和日期，跑分仍需复核。","高")
print(card.first_review(), card.state.value)

预期输出：空问题列表与“等待复核”。实际工作中主代理打开原文、去重和终审；未核验字段不为空的卡片退回。

什么情况下不该用：秒级告警或单一来源足够的简单任务，不必增加多轮复核。

Claude 模型系列第32期进阶35—50分钟API按词元计费

主备模型路由、限流重试与预算熔断

官方文档说明：429通常表示限流并可能带 retry-after；529表示全局高负载。下面用环境变量读取密钥，设置有限重试和预算熔断。

import os, time
from anthropic import Anthropic, RateLimitError, InternalServerError, APIConnectionError
client=Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"], max_retries=0)
PRIMARY=os.environ.get("CLAUDE_PRIMARY_MODEL","claude-sonnet-5-5")
BACKUP=os.environ.get("CLAUDE_BACKUP_MODEL","claude-sonnet-5")

def call(model, prompt):
    return client.messages.create(model=model,max_tokens=500,messages=[{"role":"user","content":prompt}])

def run(prompt):
    spent=0
    for model in [PRIMARY,BACKUP]:
        for attempt in range(4):
            cost=1+attempt
            if spent+cost>8: raise RuntimeError("预算熔断：停止重试，转人工处理")
            spent+=cost
            try:
                r=call(model,prompt)
                return model,r.usage.input_tokens,r.usage.output_tokens,r.content[0].text
            except (RateLimitError,InternalServerError,APIConnectionError):
                time.sleep(min(2**attempt,8))
    raise RuntimeError("主备模型均失败")
print(run("用三点说明为什么智能体必须设置停止条件。"))

验证：应打印实际模型、输入输出词元和中文回答。月度消费上限导致的429没有 retry-after，继续重试不会恢复，应直接熔断。

什么情况下不该用：主备线路属于同一故障域，或任务不可接受模型切换时不要使用盲目切换。
