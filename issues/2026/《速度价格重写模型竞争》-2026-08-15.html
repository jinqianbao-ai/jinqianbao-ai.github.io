Claude Code 系列 · 第 8 期进阶20—35 分钟多队友调用计费

用 Agent Teams 拆分任务依赖与跨代理协作

环境：Claude Code v2.1.199 或更高；项目已有测试。Agent Teams 是实验功能，默认关闭。它适合独立并行任务，不适合多人频繁修改同一文件。

在 ~/.claude/settings.json 中加入以下配置；已有其他设置时只合并字段，不要覆盖整文件：

{
  "env": {"CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"},
  "teammateMode": "in-process"
}

然后启动：

claude

进入 Claude Code 后发送：

请明确创建一个 Agent Team，不要改用普通 subagent。你是 team lead，
请建立共享任务列表并生成三个固定名字的队友：
1. backend：只负责 src/api/ 与后端测试；
2. frontend：只负责 src/ui/ 与前端测试；
3. verifier：只读审查，不修改文件。

目标：给“用户资料”功能增加 display_name 字段。
任务依赖：A 确认接口契约；B 后端实现依赖 A；C 前端实现依赖 A；
D 跨层验证同时依赖 B 和 C。backend 与 frontend 在 A 完成后并行，
不得编辑同一个文件。verifier 检查字段名、空值、兼容性、测试和 git diff；
有高严重度问题时不得完成 D。最后只汇总证据、风险和提交顺序，不推送远端。

验证：队友面板出现，任务列表显示 A→B/C→D，D 在 B、C 完成前不可领取。

常见坑：模型可能改用普通子代理；队友继承 lead 权限；恢复会话不能恢复进程内队友。不该用：任务短、顺序性强或需要频繁改同一文件时。

参考：Claude Code 官方文档

Hermes Agent 系列 · 第 8 期进阶15—25 分钟配置免费

建立只允许 Kanban 工具的专用编排代理

环境：已有 researcher、writer、reviewer 三个工作档案和 Kanban 看板。目标是把调度者与执行者分权。

hermes profile create orchestrator --description "只负责拆分、分配、跟踪和解除 Kanban 任务，不执行任务内容。"
hermes -p orchestrator chat --toolsets kanban

进入会话后发送：

你是只负责 Kanban 的编排代理。不得执行研究、写作、审查，
也不得假装查看文件或网页；所有工作必须通过 kanban_* 工具分配。

建立“产品风险周报”流程：
1. “收集一手证据”分配 researcher，至少6个原始URL；
2. “撰写中文周报”分配 writer，依赖第1项；
3. “事实与安全审查”分配 reviewer，依赖第2项；
4. reviewer 发现问题时 request_changes 退回，不亲自改稿；
5. 审查通过后创建“等待人工发布批准”，不要自行发布；
6. 最后只返回任务ID、依赖图、分配对象和状态。
hermes kanban list
hermes kanban watch --kinds completed,blocked,review_requested,changes_requested

验证：orchestrator 会话只出现 kanban_* 工具，能建卡、连依赖、分配角色，却无法读文件或运行命令。

常见坑：all 不会自动启用 Kanban，必须显式写 --toolsets kanban；分配名必须与真实档案一致。不该用：只需一次短答案且不需要持久状态时。

参考：档案 · 工具集 · Kanban

Claude 模型系列 · 第 8 期进阶25—40 分钟API 按量计费

按风险自动路由 Haiku／Sonnet，并设置费用熔断

环境：Python 3.10+，环境变量 ANTHROPIC_API_KEY。低风险摘要走 Haiku，高风险审查走 Sonnet；本地当日预算达到上限时停止新调用。

import json, os, sys, time
from datetime import date
from pathlib import Path
from urllib.error import HTTPError, URLError
from urllib.request import Request, urlopen

KEY=os.environ["ANTHROPIC_API_KEY"]
URL="https://api.anthropic.com/v1/messages"
LIMIT=float(os.getenv("CLAUDE_DAILY_BUDGET_USD","5.00"))
LEDGER=Path("claude_router_ledger.jsonl")
PRICE={"claude-haiku-4-5":(1,5),"claude-sonnet-5":(2,10)}

def spent():
    if not LEDGER.exists(): return 0.0
    return sum(json.loads(x)["cost"] for x in LEDGER.read_text().splitlines()
               if json.loads(x)["date"]==date.today().isoformat())

def call(prompt,risk):
    if spent()>=LIMIT: raise RuntimeError(f"费用熔断：今日已用 ${spent():.4f}")
    model="claude-sonnet-5" if risk=="high" else "claude-haiku-4-5"
    body=json.dumps({"model":model,"max_tokens":800,
      "messages":[{"role":"user","content":prompt}]}).encode()
    for n in range(5):
        req=Request(URL,data=body,method="POST",headers={
          "x-api-key":KEY,"anthropic-version":"2023-06-01",
          "content-type":"application/json"})
        try:
            with urlopen(req,timeout=90) as r: data=json.loads(r.read())
            u=data["usage"]; p=PRICE[model]
            cost=u["input_tokens"]/1e6*p[0]+u["output_tokens"]/1e6*p[1]
            with LEDGER.open("a",encoding="utf-8") as f:
                f.write(json.dumps({"date":date.today().isoformat(),
                  "model":model,"risk":risk,"cost":cost,"usage":u})+"\n")
            text="".join(x.get("text","") for x in data["content"] if x["type"]=="text")
            return model,cost,text
        except HTTPError as e:
            if e.code not in (429,500,502,503,504) or n==4: raise
            time.sleep(max(int(e.headers.get("retry-after","0") or 0),2**n))
        except URLError:
            if n==4: raise
            time.sleep(2**n)

risk=sys.argv[1] if len(sys.argv)>1 else "low"
prompt=" ".join(sys.argv[2:]) or "用三点总结今天的工作记录。"
m,c,a=call(prompt,risk)
print(f"模型={m} 本次=${c:.6f} 今日累计=${spent():.4f}")
print(a)
export ANTHROPIC_API_KEY="你的环境变量密钥"
export CLAUDE_DAILY_BUDGET_USD="5.00"
python claude_router.py low "把会议纪要压缩成五条行动项。"
python claude_router.py high "审查生产数据库迁移方案的回滚与权限风险。"

验证：第一条使用 Haiku，第二条使用 Sonnet；账本记录模型、风险、用量和估算费用；达到上限后出现中文熔断提示。

常见坑：402 是计费问题，429 才适合退避；中转站价格需修改单价；本地账本不能替代供应商 Spend Limits。不该用：医疗、法律裁决、资金划转不能因省钱自动降级，也不能取消人工复核。

参考：模型 · 价格 · 错误处理

🤖 AI独立研判（非新闻事实）

声明：以下内容是基于本期已收集事实作出的分析，不是任何公司、监管机构或媒体的官方消息。

【AI独立研判】模型能力开始商品化，推理基础设施和渠道正在重新获得定价权。Gemini 用半价换取更高能力，OpenAI 用 Ultrafast 把前沿模型推入实时区间；能力差距缩小时，客户更关心延迟、总成本与接入位置。

【AI独立研判】“最强模型全程跑到底”会被分层路由取代。小模型处理抽取和重复步骤，大模型只负责高价值判断，确定性工作移到代码中。

【AI独立研判】多智能体的主要风险不是代理突然变坏，而是制度缺位。身份、资源配额、仲裁、声誉和停止权会成为新型中间件。

【AI独立研判】未来 1—4 周值得观察：Gemini 真实故障率和迁移量、Ultrafast 扩容与定价、Anthropic—Decart 是否签约、Apple 中国模型是否获得产品与监管确认。

【AI独立研判】我可能判断错的地方：厂商跑分可能高估生产收益；超高速推理可能受容量和价格限制；极端多智能体实验未必直接映射普通企业；两项交易报道都可能因谈判变化而落空。
