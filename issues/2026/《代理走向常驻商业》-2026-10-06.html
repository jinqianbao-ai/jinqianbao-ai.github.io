Claude Code系列第36期

把子代理和MCP放进权限边界

难度：进阶｜动手：35分钟｜成本：按账户方案计费；代码免费｜环境：Claude Code当前版本、Git项目、可审查MCP服务器。

claude -p "只读分析当前项目：把任务拆成主代理、子代理和MCP工具三部分；列出每部分允许访问的文件、命令和停止条件；不要修改任何文件。"

claude -p "你是测试分析子代理。只读取测试文件和失败输出，给出根因候选、证据和建议验证命令；不要改文件、不要提交代码。"

claude -p "审查刚才的代理结果：检查是否越过文件和工具权限，列出需要人工确认的动作；只输出审查报告，不执行写操作。"

常见坑是把MCP当成可信插件、让子代理继承全部权限、忽略工具日志。失败时先断开MCP，用只读任务复现。生产数据库、支付、密钥轮换和不可逆删除不要无人值守。

Hermes Agent系列第36期

为常驻任务设计状态、心跳和恢复点

难度：进阶｜动手：40分钟｜成本：模型调用费用；本地编排代码免费｜环境：Hermes Agent、可持久化工作目录、只读网页检索任务。

job:
  name: daily-research
  state_file: evidence/state.json
  heartbeat_seconds: 60
  max_runtime_seconds: 1800
  steps:
    - id: collect_models
      permissions: [web_read, file_write:evidence/models.json]
      retry: 2
    - id: collect_infra
      permissions: [web_read, file_write:evidence/infra.json]
      retry: 2
    - id: review
      depends_on: [collect_models, collect_infra]
      permissions: [file_read:evidence, file_write:report.md]
      retry: 0
  recovery:
    on_timeout: save_state_and_stop
    on_partial_failure: publish_verified_steps_only

验证方法：每一步输出都包含来源、时间、状态和证据等级；中断后从最后成功步骤继续。常见坑是没有超时、重试无限、失败后把空文件当成功。一次性且不可拆分的任务不必强行编排。

Claude模型系列第36期

给中转接口增加超时、限流和故障切换

难度：进阶｜动手：35分钟｜成本：模型调用费用；代码免费｜环境：Python 3.11+、兼容接口、环境变量密钥。

import json, os, time, urllib.error, urllib.request
ENDPOINTS = [x for x in os.environ["AI_ENDPOINTS"].split(",") if x]
API_KEY = os.environ["AI_API_KEY"]
MODEL = os.environ["AI_MODEL"]
payload = json.dumps({"model": MODEL, "messages": [{"role": "user", "content": "用中文给出三条代理系统的停止条件。"}], "max_tokens": 200}).encode("utf-8")
last_error = None
for endpoint in ENDPOINTS:
    for attempt in range(2):
        try:
            req = urllib.request.Request(endpoint.rstrip("/") + "/v1/chat/completions", data=payload, headers={"Authorization": "Bearer " + API_KEY, "Content-Type": "application/json"}, method="POST")
            with urllib.request.urlopen(req, timeout=30) as response:
                data = json.loads(response.read().decode("utf-8"))
            print(json.dumps({"endpoint": endpoint, "model": MODEL, "usage": data.get("usage", {}), "answer": data["choices"][0]["message"]["content"]}, ensure_ascii=False))
            raise SystemExit(0)
        except (urllib.error.URLError, TimeoutError, KeyError, json.JSONDecodeError) as exc:
            last_error = f"{type(exc).__name__}: {exc}"
            time.sleep(2 ** attempt)
raise SystemExit("所有端点均失败：" + str(last_error))

成功输出必须包含端点、模型、回答和用量字段。先区分超时、限流、认证和服务端错误，再决定切换。高风险决策、支付和交易动作不要仅凭备用模型成功返回就继续。

参考：Anthropic API文档
