把AI代码扫描接入提交前审查：先限制权限，再让代理修复

环境与前置：Claude Code、Git、一个可运行的项目；不需要把密钥写入命令行。

# 只允许代理读取、编辑和运行项目已有测试；先审查再改动
printf '%s\n' '请先阅读 src/ 目录和现有测试。只处理一个已确认的输入校验问题：先说明根因和拟修改文件，等待我在终端批准后再编辑；完成后运行项目已有测试，并输出 git diff -- src/ 的差异摘要。不要读取 .env、密钥、用户目录和仓库外文件。' | claude -p --allowedTools 'Read,Edit,Bash'

# 人工检查差异，再决定是否提交
git diff -- src/

参考：https://docs.anthropic.com/en/docs/claude-code/cli-reference

成功标准：代理先给出范围，差异只落在预期目录，测试有真实输出。常见坑是把Bash权限给得过宽、没有检查差异、只相信代理口头总结。什么情况下不该用：涉及生产部署、支付、删除数据或不可逆迁移时，不要只靠一次非交互调用。

Hermes Agent系列｜第50期难度：进阶｜动手时间：25—35分钟｜成本：免费；模型和外部服务按实际用量计费

用可恢复检查点管理“检索—核验—写入—验收”

环境与前置：Python 3.11+；本示例只演示状态设计，不调用本地Hermes内部接口。

from dataclasses import dataclass, field

@dataclass
class DailyJob:
    urls: list[str] = field(default_factory=list)
    verified: list[str] = field(default_factory=list)
    artifacts: list[str] = field(default_factory=list)
    accepted: bool = False

def next_step(job: DailyJob) -> str:
    if not job.urls:
        return "检索"
    if len(job.verified) < 8:
        return "核验"
    if not job.artifacts:
        return "写入"
    if not job.accepted:
        return "验收"
    return "完成"

job = DailyJob(urls=["https://example.com/source"])
print(next_step(job))  # 预期：核验

参考：https://hermes-agent.nousresearch.com/docs

成功标准：每一步都有可保存的输入、输出、时间和失败原因；重试不会重复写入；验收失败可以从上一个检查点恢复。常见坑是只保存“当前步骤”而不保存证据清单，或让写入步骤不可幂等。什么情况下不该用：任务没有明确边界、没有可验证产物时，不要先堆复杂工作图。

下期预告：下期预告：把幂等键、重试退避和人工升级路径加入常驻任务。

Claude模型系列｜第50期难度：进阶｜动手时间：20—30分钟｜成本：按API实际用量计费；示例不含真实密钥

用兼容接口记录模型、用量和成本证据

环境与前置：Python 3.11+、openai Python SDK 1.x；兼容OpenAI接口的服务商地址、模型名和环境变量。

import json
import os
from datetime import datetime, timezone
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["AI_API_KEY"],
    base_url=os.environ["AI_BASE_URL"],
)

response = client.chat.completions.create(
    model=os.environ["AI_MODEL"],
    messages=[{"role": "user", "content": "只回复：成本记录成功。"}],
    temperature=0,
)

record = {
    "time": datetime.now(timezone.utc).isoformat(),
    "model": response.model,
    "text": response.choices[0].message.content,
    "usage": response.usage.model_dump() if response.usage else None,
}
print(json.dumps(record, ensure_ascii=False))

参考：https://github.com/openai/openai-python

成功标准：输出包含时间、实际模型名、回复和usage字段；没有usage时不要自行猜成本。401通常是密钥或地址错误，404通常是模型名或路径不匹配，429表示限流；如果服务商不完全兼容该接口，应改用其官方SDK。什么情况下不该用：涉及医疗、金融或生产决策时，不要把一次API调用当作充分验证。

下期预告：下期预告：故障切换、限流重试和上下文压缩，避免成本和延迟失控。
