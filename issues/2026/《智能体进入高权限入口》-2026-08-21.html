为什么重要： AI 算力扩张不再只影响芯片股、电价和土地，也开始传导到全社会融资成本。若利率保持高位，模型公司的资本效率、数据中心利用率和长期合约质量会变得比“买到多少 GPU”更重要。

① Claude Code 系列第 13 期：用 PermissionDenied 钩子记录自动拒绝并允许安全重试

难度：进阶｜预计动手时间：25 分钟｜成本：免费｜环境：Claude Code 当前官方 Hooks 机制、Python 3.9+｜前置：能编辑项目的 .claude/settings.json

适用场景： 你使用 Claude Code 自动模式，希望区分“模型安全分类器拒绝”“没有给出分类结论的拒绝”和“可以改写后重试的工具调用”。官方文档说明，PermissionDenied 在自动模式拒绝工具调用时触发；命令钩子可返回 hookSpecificOutput.retry: true 告诉模型可以重试，但不会撤销原拒绝，而且对“无分类结论”的拒绝无效。

  1. 在项目中新建 .claude/hooks/permission_denied.py，完整内容如下：
#!/usr/bin/env python3
"""记录 Claude Code 自动模式拒绝；仅对白名单只读命令允许模型改写后重试。"""
import json
import pathlib
import sys
from datetime import datetime, timezone

payload = json.load(sys.stdin)
tool_name = str(payload.get("tool_name", "未知工具"))
tool_input = payload.get("tool_input", {})
command = str(tool_input.get("command", "")) if isinstance(tool_input, dict) else ""

# 只把明显只读的 Bash 命令列为“可安全改写后再试”；不要给写文件或删除命令自动重试。
safe_prefixes = ("git status", "git diff", "git log", "pwd", "python -m pytest")
allow_retry = tool_name == "Bash" and command.startswith(safe_prefixes)

record = {
    "时间": datetime.now(timezone.utc).isoformat(),
    "工具": tool_name,
    "命令": command,
    "允许模型重试": allow_retry,
    "原始事件": payload,
}
log_path = pathlib.Path(".claude/permission-denied.jsonl")
log_path.parent.mkdir(parents=True, exist_ok=True)
with log_path.open("a", encoding="utf-8") as f:
    f.write(json.dumps(record, ensure_ascii=False) + "\n")

print(json.dumps({
    "hookSpecificOutput": {
        "hookEventName": "PermissionDenied",
        "retry": allow_retry
    }
}, ensure_ascii=False))
  1. 在 .claude/settings.json 中加入完整配置；如果文件已有其他设置，请把 hooks 对象合并进去，不要覆盖原内容：
{
  "hooks": {
    "PermissionDenied": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "python .claude/hooks/permission_denied.py",
            "timeout": 10
          }
        ]
      }
    ]
  }
}
  1. 在自动模式中触发一次需要权限判断的只读 Bash 调用。成功标志是 .claude/permission-denied.jsonl 新增一行；若命令以白名单前缀开头，钩子只会告诉模型“可以改写后重试”，不会替模型绕过拒绝。

常见坑： PermissionDenied 已发生后，脚本退出码和标准错误不会改变结果；必须从标准输出返回合法 JSON。官方还明确说明，提示词钩子或智能体钩子不能设置这个 retry 字段，应使用命令钩子。不要把 rm、写文件、发布或转账命令加入自动重试白名单。

什么情况下不该用： 需要人工批准的生产写入、部署、密钥、付款和数据删除操作，不应允许自动重试。

参考：Claude Code Hooks 官方文档
https://code.claude.com/docs/en/hooks

② Hermes Agent 系列第 13 期：工作树加检查点，建立分支级与会话级双层恢复

难度：进阶｜预计动手时间：20 分钟｜成本：免费｜环境：Hermes Agent v2 文档所述检查点机制、Git 仓库｜前置：已安装 Hermes，项目已由 Git 管理

适用场景： 上一期已经用 Git worktree（工作树）把研究、写作和复核隔离；本期在每个工作树内启用 Hermes checkpoint（检查点），让“大方向”由 Git 分支保存，“单轮误改”由 /rollback 恢复。官方说明检查点默认关闭，并存入独立影子仓库，不修改项目自己的 .git。

  1. 在 Hermes 交互会话中创建隔离工作树：
/worktree new ai-daily-review

Hermes 会创建 .worktrees/ai-daily-review/ 和对应分支，并把当前会话的终端与文件工具切换过去。

  1. 如果从新会话开始，在仓库根目录运行：
hermes chat --checkpoints
  1. 完成一轮修改后，在会话内查看检查点：
/rollback
  1. 恢复前先预览差异，其中 N 是列表中的检查点编号：
/rollback diff N
  1. 只恢复单个文件，避免覆盖其他人工修改：
/rollback N path/to/file
  1. 需要恢复整个检查点但保留手工改动时：
/rollback N

只有在明确知道会覆盖手工改动时才使用：

/rollback N --all

验证方法： /worktree 应显示当前隔离目录；/rollback 应列出该工作树自己的检查点和变更统计。官方文档说明，不同工作树按路径使用独立检查点历史，因此一个会话回滚不会影响另一个工作树。

常见坑： 检查点每个目录每轮最多创建一次，不能替代正式提交；大文件可能因配置上限被跳过。不要在未看 /rollback diff N 的情况下直接使用 --all。长期成果仍应 git add、git commit 并推送远端。

什么情况下不该用： 非 Git 项目、包含大量超大二进制文件的目录，或必须由数据库事务恢复的系统，不应把文件检查点当成完整备份。

参考：Hermes Agent 官方文档
https://hermes-agent.nousresearch.com/docs/user-guide/git-worktrees
https://hermes-agent.nousresearch.com/docs/user-guide/checkpoints-and-rollback

③ Claude 模型系列第 13 期：用 Count Tokens API 建立真实词元预算门禁

难度：进阶｜预计动手时间：25 分钟｜成本：计数接口不生成回答，正式请求按模型计费｜环境：Python 3.9+ 标准库、Claude API｜前置：设置 ANTHROPIC_API_KEY 与 CLAUDE_MODEL 环境变量

适用场景： 上一期用字符数估算每分钟输入预算，本期改用 Anthropic 官方 Count Tokens API（词元计数接口）。它会计算消息中的文本、工具、图片和文档所占词元，但不会真正生成回答。

把下面代码保存为 claude_budget_gate.py：

#!/usr/bin/env python3
"""先调用 Claude Count Tokens API；超过预算就拒绝正式请求。"""
import json
import os
import sys
import urllib.error
import urllib.request

API_KEY = os.environ["ANTHROPIC_API_KEY"]
MODEL = os.environ["CLAUDE_MODEL"]
MAX_INPUT_TOKENS = int(os.getenv("MAX_INPUT_TOKENS", "12000"))
API_VERSION = "2023-06-01"

messages = [{
    "role": "user",
    "content": "请用中文总结下面资料，并列出三条需要人工核验的事实：\n" + sys.stdin.read()
}]


def post(path: str, body: dict) -> dict:
    request = urllib.request.Request(
        "https://api.anthropic.com" + path,
        data=json.dumps(body, ensure_ascii=False).encode("utf-8"),
        headers={
            "x-api-key": API_KEY,
            "anthropic-version": API_VERSION,
            "content-type": "application/json",
        },
        method="POST",
    )
    try:
        with urllib.request.urlopen(request, timeout=90) as response:
            return json.loads(response.read().decode("utf-8"))
    except urllib.error.HTTPError as exc:
        detail = exc.read().decode("utf-8", "replace")
        raise SystemExit(f"Claude API 请求失败，状态码 {exc.code}：{detail}")


base_body = {"model": MODEL, "messages": messages}
count = post("/v1/messages/count_tokens", base_body)
input_tokens = int(count["input_tokens"])
print(f"计数结果：{input_tokens} 个输入词元；预算上限：{MAX_INPUT_TOKENS}")

if input_tokens > MAX_INPUT_TOKENS:
    raise SystemExit("超过预算：请先分段、摘要或移除无关附件，再发送正式请求。")

result = post("/v1/messages", {
    **base_body,
    "max_tokens": 800,
})
text = "".join(block.get("text", "") for block in result.get("content", []))
print("\nClaude 回答：\n" + text)

运行命令：

export ANTHROPIC_API_KEY="你的密钥"
export CLAUDE_MODEL="你账号当前可用的模型ID"
export MAX_INPUT_TOKENS="12000"
python claude_budget_gate.py < long_article.txt

预期输出： 程序先打印真实输入词元数；低于上限才调用 /v1/messages，超过上限则在产生正式生成费用前退出。模型 ID 不在示例里写死，是为了避免读者复制已经退役或无权限的型号。

常见报错： 状态码 401 通常是密钥缺失或错误；404 常见于模型 ID 不可用；429 表示速率或词元预算超限；如果输入包含图片、文档或工具定义，应把相同结构同时传给计数和正式请求，否则预算会失真。

什么情况下不该用： 极短、低频、无成本压力的交互不必每次先计数；计数本身也增加一次网络往返。

参考：Anthropic Claude API 官方文档
https://platform.claude.com/docs/en/api/messages/count_tokens
